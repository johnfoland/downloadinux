# Chunk P0002-C03 — Writable application home without changing history data

**Source:** project [P0002](../projects/P0002-stage1-followups.md), §5 delivery
item D3 (all of it), resolving
[#22](https://github.com/johnfoland/downloadinux/issues/22), and §6 completion
evidence. Authority: target design *Container contract*, "Runtime home
ownership, pinned for P0002" (DEC-26), and the existing DEC-9 identity contract.

**Goal:** The configured runtime user owns the four application-home directory
entries even when Docker created their parents as root. Startup repairs those
entries without recursively changing retained data or following a final symlink.
The gate proves the ownership and write boundary in a credential-free Linux
container, and the report gathers the evidence needed for P0002's closeout.
